## Interpretation order (with amendments)

1. Owner explicit instruction
2. `QUANTLAB_CONSTITUTION.md` + Owner-approved Amendments (this registry)
3. Current QLN phase acceptance criteria
4. Autonomous Engineering Pack

If an Amendment and the base Constitution conflict on mission / product value / commercial doctrine, the **later Owner-approved Amendment** governs that topic — unless the Amendment explicitly says it does not change a listed boundary (QLN order, Live Gate, AE bounds, `NEXT_PHASE_AUTO_ENTER`, etc.).

# QuantLab AI · 产品说明 (README_PRODUCT)

> 一句话:**让一个完全不懂量化的小白,打开网页后,在一次会话里完成自己的第一个研究成果。**

QuantLab AI 不是"量化交易软件",而是一个 **量化研究员孵化器 + 研究行为沉淀平台 (Research OS)**。
我们关心的不是"能不能下单赚钱",而是"用户能不能像科学家一样做研究":提出假设 → 实验 →
验证 → 复盘 → 沉淀。

## 产品定位

- 不做:实盘交易、自动下单、真钱实盘（LIVE 默认关闭；交易核心为 NautilusTrader）。
- 做:培养研究习惯 + 沉淀可复现的研究资产 + 用积分/排行榜/主页激励长期成长。
- 核心资产:**研究过程数据**(假设、因子、回测、验证、报告、研究路径图谱)。

## 用户闭环 (Research OS)

```
注册 → 学习任务 → 创建研究项目 → 创建因子 → 回测 → 科学验证
     → 生成研究报告 → 发布研究成果 → 获得研究积分 → 进入排行榜
```

这条"北极星路径"由集成测试 `backend/tests/test_full_path.py` 守护,保证它始终能跑通。

## 研究项目 (ResearchProject)

项目是闭环的起点:用户先定一个**研究主题**(如"螺纹钢趋势是否有延续性"),
在项目下造因子 → 回测 → 验证 → 报告。项目状态:`draft → active → published`,
发布后进入研究 Feed 供他人查看。

## 研究路径图谱

`GET /projects/{id}/graph` 由项目产物物化出 `假设 → 实验(因子/回测) → 验证 → 结果(报告)`
的有向图,把"过程 > 结果"变成可视化资产,也是后续社区/教学的素材。

## AI 研究助手:从"复盘"到"指导"

- 复盘:对回测/验证给出通俗结论与下一步建议。
- 指导:`POST /ai/research-plan { theme }` 给一个方向,返回研究假设(对应可量化因子)
  + 推荐实验(窗口/敏感性/样本外/跨品种)。
- 强约束:**只给研究方法,不给买卖点,不承诺收益**。无 LLM key 时自动回退到本地确定性规则。
